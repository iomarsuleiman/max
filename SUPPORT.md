# Support

Max is in pre-alpha planning. There is not yet a released application or hosted service.

- **Bug reports and feature requests:** open a GitHub issue using the templates.
- **Questions:** use GitHub Discussions if enabled; otherwise open a clearly labeled question issue.
- **Security issues:** use the private process in [SECURITY.md](SECURITY.md), not public issues.
- **Implementation plan:** see [docs/ROADMAP.md](docs/ROADMAP.md).

Community support is best effort; response times are not guaranteed.
