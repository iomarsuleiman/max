# Roadmap

The complete implementation plan and engineering budgets live in the [Max Notion plan](https://app.notion.com/p/412448cf001c81e6b333fcb85d6a8533).

## Stages

1. Repository/bootstrap and open-source governance
2. Clerk authentication and Convex owner-scoped notes
3. Workspace, nested pages, search and organization
4. BlockNote editor and reliable autosave
5. Personal databases and complete MCP/UI feature parity
6. Responsive design, OKLCH tokens, RTL, accessibility and exports
7. Security, benchmarks, CI and release validation

All features above are planned, not completed. No collaboration or standalone editor package extraction is required.
